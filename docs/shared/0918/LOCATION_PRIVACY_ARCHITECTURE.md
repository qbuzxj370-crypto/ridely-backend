# 위치정보 처리 방침 — 서버 무전송 원칙 (2026-09-18)

## 원칙

**기기 GPS로 얻은 정보는 원본이든 가공값(거리·속도·궤적 등)이든 그 어떤 형태로도 Ridely 백엔드 서버에 전송하지 않는다.** 예외 없음.

위치정보의 보호 및 이용 등에 관한 법률(위치정보법)상 개인위치정보 수집·보관에 해당할 여지를 원천 차단하기 위한 결정이다. 서버가 처음부터 받지도, 갖지도 않으면 신고·보관·유출 리스크 자체가 성립하지 않는다.

**주의**: 이건 "법적으로 100% 안전을 보장"하는 문서가 아니라, 우리 서버가 개인위치정보를 수집·보관하지 않는다는 기술적 사실을 만드는 조치다. 정확한 법적 판단이 필요하면 별도로 자문받을 것.

**자문 확인 (담당자 전달 기준, 2026-09-19)**: 자문에서 「위치정보가 프론트에서만 처리되면 문제없다」는 취지로 확인받았다. 그래서 위치와 무관한 데이터를 통째로 받아 폰에서 GPS로 거르는 방식(`GET /pois/all`)을 허용하고, GPS 좌표나 그것을 뭉갠 값·격자 번호를 서버로 보내는 것은 계속 금지한다. 자문의 정확한 범위(예: 동의 문구)는 원문을 확인할 것.

## 범위

이 원칙은 **Ridely 자체 백엔드**로 한정한다. 카카오맵 SDK, OpenRouteService(ORS) 같은 외부 지도/라우팅 서비스는 지도 렌더링·경로 계산을 위해 좌표를 필연적으로 받는다 — 이건 지도 기능을 쓰는 모든 앱이 마찬가지고, 이걸 없애려면 지도 기능 자체를 포기해야 하므로 대상에서 제외한다.

## 기능별 변경 사항

| 기능 | 기기 GPS 사용 | 서버 전송 | 비고 |
|---|---|---|---|
| 코스 추천 (`route-plan.js`) | ❌ 사용 안 함 | 사용자가 **검색해서 고른 장소**의 좌표만 | GPS 버튼(`useCurrentLocation()`) 제거, 장소 검색(`/geo/search`)으로만 출발/도착 선택 |
| 라이딩 실시간 추적 (`riding.js`) | ✅ 로컬 계산에만 사용 | ❌ 전혀 없음 | 거리·속도·궤적·사고다발지 근접 판정 전부 클라이언트에서 계산 |
| 라이딩 세션 기록 | - | ❌ 전혀 없음 | 세션 시작/종료 모두 서버 API 호출 자체를 없앰. 전 구간 로컬(`localStorage`, `ride-storage.js`) 저장 |
| 라이딩 이력 조회 (`riding-history.js`) | - | ❌ 없음 (조회 없음) | 로컬에 저장된 세션 목록을 읽어서 표시 |
| 마이페이지 누적 통계 (`mypage.js`) | - | ❌ 없음 (조회 없음) | 로컬 저장 데이터로 직접 합산 계산 |
| 홈 인프라 검색 (`/pois/nearby`) | ❌ 사용 안 함 | 지도 중심 좌표만 | 원래도 GPS 아님(기본값 하드코딩 or 검색한 장소) — 변경 없음, 확인 차 기재 |
| 홈 관광지 표시 (`/tours/nearby`) | ❌ 사용 안 함 | 지도 중심 좌표만 | 인프라 검색과 같은 방식(2026-09-19 추가). 상세는 관광지 번호로만 조회(`/tours/{id}`) — 위치정보 아님 |
| 홈 「내 주변 인프라 보기」 | ✅ GPS를 **한 번 읽어 폰 안에서만** 사용 | 「전부 주세요」(`GET /pois/all`, **파라미터·쿼리스트링 없음**)만 | 2026-09-20 추가. 받은 전체 목록을 폰에 저장(`infra-store.js`)하고 GPS와의 거리를 폰에서 계산해 반경으로 거른다. 요청에 위치가 없으므로 서버는 사용자가 어디 있는지 알 수 없다. **API에 좌표·반경·격자를 붙이지 않는 것이 이 방식의 전제**(테스트 `PoiAllTest`가 위치 파라미터를 줘도 응답이 같은지 고정) |
| 라이딩 중 관광지 근접 안내 | ✅ 로컬 계산에만 사용 | ❌ 전혀 없음 | 2026-09-19 추가. 코스의 관광지와의 거리를 폰에서 계산(`haversineM`), 안내 여부를 서버에 알리지 않음 |

## 남는 리스크 / 트레이드오프

- 라이딩 기록이 기기 로컬에만 남아 — 앱 삭제, 기기 변경, 앱 데이터 초기화 시 기록이 완전히 사라짐. 여러 기기 간 동기화 불가
- "현재 위치에서 출발" 편의 기능 없어짐 — 사용자가 항상 장소를 검색해서 골라야 함
