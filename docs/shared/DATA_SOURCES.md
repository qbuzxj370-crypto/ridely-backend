| 시설 종류 | 건수 |
|---|---|

- https 미지원. `http` + 8088 포트 고정
- 1,000건 응답이 수 MB라 WebClient 기본 버퍼(256KB)로는 받을 수 없다
- **JSON 루트 키가 서비스명과 다를 수 있다** — 2.4·2.7 참조

### 2.10 공간정보 오픈플랫폼 WMS/WFS *(미채택)*

| 항목 | 내용 |
|---|---|
| 제공기관 | 국토교통부 (V-World) |
| 엔드포인트 | `https://api.vworld.kr/req/wfs` |
| 레이어 | `lt_p_bycracks` (자전거보관소) |
| 인증키 | `V_WORLD_KEY` (도메인 등록 필요) |

2.6과 비교하기 위해 실호출했다. GeoJSON·WGS84로 응답하고 속성도 대응하지만 **고유 관리번호가 없어** UPSERT를 할 수 없다. 2.6을 채택했다.

### ⚠️ 이용약관 제약이 공공데이터포털과 다르다

V-World는 공공누리가 아니라 **자체 이용약관**을 적용한다. 제약이 훨씬 강하다.

> **제19조(저작권) ②** 회원은 서비스를 이용하여 얻는 정보를 **사전 승낙 없이 복사, 복제, 변경, 번역, 출판, 방송, 기타 등의 방법으로 사용하거나 이를 타인에게 제공할 수 없습니다.**

> **금지행위** — 운영기관의 동의 없이 **영리를 목적으로 서비스를 이용하는 행위**

우리가 하려던 건 WFS 응답을 **DB에 적재(복제)하고 가공해 서비스로 제공**하는 것이라 이 조항에 걸릴 소지가 있다. 반면 2.6(행안부)은 "이용허락범위 제한 없음"이다.

고유키 부재만으로도 미채택을 고려했고 **약관만 봐도 같은 결론이 나온다.** 재검토하게 되더라도 이 조항을 먼저 확인해야 한다.

**호출 시 주의** (재검토할 경우를 대비해 남긴다)

- `OUTPUT=application/json` → GeoJSON, `SRSNAME=EPSG:4326` → WGS84
- 기본 좌표계가 `EPSG:900913`(미터)이라 `SRSNAME` 명시가 필수다
- `EPSG:4326`일 때 BBOX 축 순서가 뒤집힌다 — `(ymin,xmin,ymax,xmax)`
- 서버 호출 시 `DOMAIN` 파라미터에 발급 시 등록한 도메인을 넣는다

## 3. 파일 데이터 배치 방법

### 방침

**기관 원본 파일은 공개 저장소에 커밋하지 않는다.**

자전거길 DB는 이용허락범위 제한이 없어 법적으로는 재배포가 가능할 것으로 보인다.
그럼에도 커밋하지 않는 이유는 **공개 저장소에 기관 데이터를 통째로 올리는 것이 적절하지 않다**는 판단이다. 우리 저장소는 서비스 코드를 두는 곳이지 공공데이터 미러가 아니다.

| 대상 | 공개 저장소 | 팀 내부 공유 |
|---|---|---|
| 기관 원본 ZIP·CSV | ❌ | 각자 `data.go.kr`에서 직접 |
| UTF-8 변환본 | ❌ | ✅ |
| 적재 코드·변환 스크립트 | ✅ | — |

### 배치 경로

`db/seed/`는 `.gitignore` 대상이다.

```
db/seed/
  ├─ 자전거길_노선좌표.csv
  └─ 자전거길_주변시설.csv
```

| 파일 | 출처 |
|---|---|
| 자전거길_노선좌표.csv | 자전거길 DB (`data.go.kr/data/3038533`) ZIP 내 `★국토종주 자전거길 노선좌표.csv` |
| 자전거길_주변시설.csv | 같은 ZIP 내 `★국토종주자전거길 주변시설 좌표정보.csv` |

**인코딩은 CP949 그대로 두면 된다.** 적재 코드가 변환한다.

파일이 없으면 적재가 실패한다. 오류 메시지에 이 경로가 안내된다.

## 4. 공공데이터가 아닌 외부 서비스

출처표시 대상은 아니지만 이용약관과 무료 한도가 별도로 적용된다.

| 서비스 | 용도 | 인증키 | 비고 |
|---|---|---|---|
| openrouteservice | 자전거 경로 라우팅 | `ORS_API_KEY` | OpenStreetMap 기반. 무료 한도 확인 필요 |
| Kakao Local | 주소·장소명 → 좌표 | `KAKAO_REST_API_KEY` | 백엔드 전용 |
| Kakao Map JS | 지도 렌더링 | `KAKAO_JS_API_KEY` | 프론트 전용 |
| Google Gemini | 코스 설계·코멘트 생성 | `GOOGLE_API_KEY` | `gemini-2.5-flash` |

**ORS 검증 결과** (선유도공원 → 여의도한강공원)

- `distance` 4,822.9m — 직선거리 3.9km 대비 정상. **한강 자전거길을 제대로 탄다**
- `ascent` 137.9m인데 같은 응답의 고도 범위가 1~32m다. **SRTM 노이즈로 과대 계상된다.**
  `total_ascent_m`·`estimated_duration_min`에 영향이 간다
- `elevation:true`면 bbox가 **6개 값(3D)**이다
- `instructions:false`를 넣어 불필요한 턴바이턴 데이터를 줄인다
